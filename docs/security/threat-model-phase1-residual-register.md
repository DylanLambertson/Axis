# Threat model: Phase 1 residual-risk register (owner and ticket per item)

- **Status:** Draft for review. Part of the Phase 1 revision: `threat-model-phase1-revision-1a.md` (controls as built, new threats N-1 to N-14). Date 2026-11-05, code baseline `origin/main` `74cd12e`.
- **Verified against:** `origin/main` `74cd12e` (PRs #455 and #454 included). Branch heads read: `feat/composer-runtime` `f36cdd5`, `feat/events-e1` `2955bf9`, `feat/protocol-worktrees-tier4` `f001dd8`, `feat/pty-process` `e0bd16c`. Main keeps moving: re-check every **[B]** row against git before the gate review.
- **Since baseline (X1 merged):** the daemon entry, supervisor and Axis main seam (X1, PR #454) are merged on main as `74cd12e`; rows that said they were on a branch or open are now **[M]**. Main's answers to the control channel (`trust.check`, `anchor.get`/`anchor.put`, `native.confirm`, `settings.get`: ticket X1c) are **still not on main**: the seam passes no `onRequest`, so the host reads them as degraded, declined, untrusted and refused. The daemon is forked in unpackaged builds only and still refuses to start (exit 78) until the pty process (B9) exists (the run snapshotter is wired, H13).
- **What this is.** Every risk that is accepted, open or deferred for the Phase 1a gate review and for 1b, with the owner (the package or workstream that carries the fix), the ticket, and the gate line. Original scores (R1 to R33, controls file §9) are not repeated; the "Risk" column names the row the item belongs to.
- **Decision authority.** Accepting any item below is the project owner's decision (Dylan Lambertson). "Owner" here means the workstream that must do the work.
- **Ticket column.** An id from `docs/design/daemon-host-plan.md` (H, P, J, FU, E, X, W, B tickets) or `docs/design/composer-runtime.md` on branch `feat/composer-runtime` (C and J tickets) is a real row. **"proposed"** marks an id invented in this file; each proposed id has a one-line row added to `docs/design/daemon-host-plan.md` in the same change, so none dangles. Rows that exist only on `feat/composer-runtime` say so. **"none"** says no ticket exists and none is proposed (an accepted risk).
- **Status words:** **Open** (control not built), **Accepted** (decided, with the wording the product uses), **Branch** (fix exists on an unmerged branch), **Deferred** (a later phase owns it).

## 3. How to read the gate review against this register

- A 1a gate line is **ready for review** only when every register item that names it is **Accepted**, **Deferred** or closed. Open items against 1a/L2, L3, L10, L14, L15, L17, L18, L24 and L25 are blocked on B9, the snapshotter wiring (RR-3) and the main seam.
- The slice (`packages/daemon-host/test/slice/`) is evidence for the daemon half of L7, L8, L10 (kill and recover), L20 and L24 **with the fakes named in the compose doc**. It is not evidence for the process-group contract.
