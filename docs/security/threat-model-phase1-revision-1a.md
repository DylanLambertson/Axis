**Conventions.** "Slice step n" is the numbering of `docs/design/daemon-host-plan.md` §1.2, not a test name (the tests are `packages/daemon-host/test/slice/headless*.test.ts`). **Gate line 1a/L12** (this revision) is satisfied by this file plus review of the residual register; it is not otherwise mapped below. **[R]** notes are time-bound: each says the head it was written against or has been updated to the heads above.

**Evidence tags.**

- **[M]** built and merged on main; the cited file or package page records the behaviour and its tests.
- **[B]** built on a named branch that is not on main; re-check at merge.
- **[R]** a defect or gap raised by an independent review of a branch or PR; recorded here as a threat, not independently re-verified for this file.
- **[I]** inferred. **[D]** design only, nothing built.
- **Built** means code exists. It does not mean the gate line passes: gate lines need an Electron or Code OSS run for the UI parts (see the unverified-gates file).

## 1. What changed in the phase order

ADR 0004 splits Phase 1 into **1a (agent workspace shell, CLI agents, review and push)** and **1b (composer and brokered agent)**. 1a ships first and 1b reuses its challenge and audit mechanisms. Four consequences for the threat model:

1. **1a is mostly a daemon problem, and the daemon host now exists.** `@axis/daemon-host` (#50 to #445) answers real requests in the headless child-process slice over a repository and bare remote. H13 (`13b036f`) replaced its no-op run snapshotter with the real `@axis/git-snapshot` binding; the test still supplies a test pty and main (`docs/design/daemon-host-compose.md`).
2. **The remaining 1a pieces are on the trust boundary.** B9 (`86247ab`, `5baee0a`), H13 (`13b036f`), X1b/X1c (`2a0acff`), E1 (`116ef22`) and the production pty handover (`25e539c4`) are on main. H9-hooks S1 (`2497928`, `7fe8311`) and S4 part 1 (`3f02f3fc`) are built; the host commit-hook step and pre-push hook path remain open (`docs/design/daemon-host-hooks.md` §9).
3. **1b has a daemon composer slice.** C1 (`f7ca129`), C2 (`21497cd`), C3 slices 1 and 2 (`cb227ca1`, `bb12ee10`), C4 (`6b5d50f`), C5/C9 (`bb6bd08`), C6 (`812df0c7`), C7 (`2c4b704e`), C8/S4 (`5e4e797`), C10/J2 (`d47fb8a`) and C11 (`560e6ae`) are on main. C12 hooks placement and the named follow-ups remain open (`docs/design/composer-runtime.md`).
4. **New trust boundaries.** Add to TB1 to TB11 of the model:
   - **TB12: supervisor (Electron main, or a test parent) to the daemon host process.** Identity comes from per-spawn signed attestations on one control channel. X1 and X1b/X1c are merged (`74cd12e`, `2a0acff`); desktop main answers the control requests (`docs/design/main-answers.md`).
   - **TB13: daemon to event subscribers (E1, merged as `116ef22`).** Server push uses bounded invalidation hints; section 3, N-8.
